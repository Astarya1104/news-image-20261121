# The World in One Picture — Saturday 21 November 2026

An entry for make.fun's "Sum up 21 November's world news in one image" bounty.

`main.py` (Python 3.13, standard library only) renders one 1024×1024 front page summing up Saturday 21 November 2026 — COP31 running into overtime with no deal, three missiles downed over Riyadh, and BepiColombo reaching Mercury after eight years — plus 38 more real stories from that day across six regions, with an explicit date check excluding Friday's news.
